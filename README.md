# Análise de Vendas de Veículos - Dashboard Web

Este projeto é uma aplicação web interativa desenvolvida com **Streamlit** e **Plotly Express** para análise exploratória de dados de vendas de carros.

## Funcionalidades
- Visualização de histograma interativo da quilometragem (`odometer`).
- Visualização de gráfico de dispersão interativo (Preço vs. Odômetro).
- Filtros via caixas de seleção (`st.checkbox`).

## Como rodar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
